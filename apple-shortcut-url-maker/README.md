# Make an IOS Shortcut URL

[Shortcuts can be run on IOS devices using a specific URL scheme.](https://support.apple.com/en-mo/guide/shortcuts/apd624386f42/ios)
Use this CLI tool to generate a basic version for use with NFC tags.

> **NOTE:** Trying to run shortcuts this way always requires a confirmation.
> If you want to run them automatically when a tag is scanned, use the
> "Automation" tab in the IOS shortcuts app to set up a *Trigger*.
> Just remember that **in order for an NFC trigger to work, the screen must be on when you can the tag.
