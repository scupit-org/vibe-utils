# Vibe Utils — Agent Instructions

## Repository structure

This is a personal collection of small tools and guides.

- Each **project** lives in its own top-level directory (e.g. `apple-shortcut-url-maker/`, `mcp-ecosystem/`).
- All **guides** live under `guides/`, grouped into subdirectories by topic (e.g. `guides/gpg-and-cursor-cloud-agent-signing/`).

## Keeping the index up to date

`README.md` at the repository root is the index for this repo. It contains two tables:

- **Projects** — one row per project directory
- **Guides** — one row per guide document

When you add a new project or guide, add a corresponding row to the relevant table in `README.md`. Each row should include a relative link and a concise one-sentence description. Do not remove or reorder existing rows.
